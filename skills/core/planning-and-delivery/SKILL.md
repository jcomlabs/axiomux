# Planning and Delivery

## Procedure

1. Establish scope, constraints, existing state and measurable outcome.
2. Decompose into independently verifiable steps with at most one active step.
3. Keep facts, decisions and proposals distinct.
4. Persist workflow state after each step that matters.
5. Implement in coherent slices and validate each slice.
6. Finish with the outcome, evidence, files changed and known limits.
