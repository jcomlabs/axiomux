# Core skills

These skills are native to Axiomux and are loaded progressively by metadata and task match.

Several methods are original adaptations inspired by the MIT-licensed [obra/superpowers](https://github.com/obra/superpowers). They are rewritten for Axiomux's policy and runtime; they are not a vendored copy of the upstream skill text. See `THIRD_PARTY_NOTICES.md` and `SOURCES.md`.
